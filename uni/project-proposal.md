## Description

**Title**: Ortaq - OSI management tool.
**Background**: The main benefit of the project is to create transparency between OSI and residents in terms of problems solving and budget distribution, automate most of the processes for OSI chairman using available IT and AI tools, and overall create comfortable environment for residents, as well as easy management.
**Goals and Objectives**: B2B web platform for OSI management (chairman and all the employees), and B2C mobile application for residents that connects to the web platform; also integrate basic AI tools, such as chat bot that answers questions regarding current situation in the building, and summarizes budgeting; employees of the OSI will use the same mobile applications to see their current tasks or routines (tasks that happen on schedule - yard cleaning).
**Scope**: 
*OSI side*: Budget Diagram - see who has paid monthly fee and who hasn't (and overall budget); Add payment check for the diagram; Monthly Report; Tasks Manager (applications from residents and other internal tasks); Photo collection for each task (before, after); Delegation tool (Button to delegate a task to an employee, and automatic AI task distribution); AI chat bot for legal questions; Create Voting; Create Announcement (for residents or for employees);
*Resident Side*: Budget Overview (the money goes); Voting; Announcement Overview; Submit Application with photo and place; See completion of Applications; Attach payment check (to verify that you have paid).
**Expected Deliverables**: Web mock ups, Mobile mock ups, Working Web Prototype, Working Mobile Prototype, Competitor Research, Business Analysis (Value, MRR).
**Impact**: The Product will improve communication between residents and chairman by making problem solving and budgeting transparent, help to solve building problems faster, help chairman to delegate tasks for the employees and create reports without any effort.
